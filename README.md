# Sistema de control de inventario

Sistema de control de inventario con arquitectura híbrida (offline-first) desarrollado para optimizar los procesos de recepción, trazabilidad y gestión de stock en tiempo real.

---

## Stack Tecnológico

* **Frontend:** Interfaz de Escritorio (.NET 8)
* **Backend:** .NET 8 Web API
* **Base de Datos:** Relacional SQL Server (Sincronización Híbrida: Servidor Local y Respaldo Nube)
* **Gestión:** GitHub Projects (Metodología Scrum)

---

## Módulos del Sistema

* **Módulo de Seguridad:** Autenticación de usuarios y gestión de permisos.
* **Módulo de Procesos:** Gestión de entradas/salidas, recepciones, devoluciones, transferencias entre sucursales y alertas de stock bajo.
* **Módulo de Mantenimientos:** Catálogos de artículos, marcas, modelos, almacenes, categorías y estados (disponible, reservado, en tránsito).
* **Módulo de Consultas e Informes:** Consultas de existencias en tiempo real, trazabilidad de historial y reportes automáticos.
* **Servicio de Sincronización:** Agente en segundo plano para replicación de datos en contingencias u operación offline.
